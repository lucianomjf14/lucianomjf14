## Projetos

### [Recibos Brasil](https://recibosbrasil.com)

Plataforma web para emissão e gestão de recibos digitais, com geração de PDF, autenticação, gestão de clientes e integração com pagamentos. O desenvolvimento inclui testes automatizados e integração contínua.

`React` · `TypeScript` · `Supabase` · `PostgreSQL` · `Stripe`

### BancoTV

Aplicação para jogos de tabuleiro físicos que conecta os celulares dos jogadores a uma tela compartilhada. Reúne entrada por QR Code, saldos, transações em tempo real e recursos de recuperação de partidas.

`JavaScript` · `PeerJS / WebRTC` · `QR Code`

### Sistema de ordens de serviço

Aplicação web para equipes de campo, com checklists, acompanhamento de execução e assinaturas. O projeto inclui testes automatizados de permissões e de jornadas completas em navegadores desktop e mobile.

`JavaScript` · `Firebase` · `Playwright` · `PWA`

### [Painel de Comando](https://github.com/lucianomjf14/Painel-de-Comando)

Ferramenta em Python para automatizar rotinas no Google Workspace, com interface web e CLI. Integra Gmail, Drive e Sheets, além de processamento de documentos com OCR.

`Python` · `Flask` · `Google APIs`

### LMS Academy

Plataforma de cursos on-line em desenvolvimento, com arquitetura multi-tenant, autenticação, componentes de cobrança e testes de isolamento de dados.

`Next.js` · `TypeScript` · `PostgreSQL` · `Prisma`
